# أدوات توليد الصوت وتصحيحه ونشره

هذه أدوات Algieba التي كانت محلية في جلسة العمل، مع اختبارات تعمل من نسخة
جديدة للمستودع دون توكنات أو تسجيلات الإنتاج. الأداة العامة الموجودة سابقًا
هي `scripts/generate_dua_audio.mjs`؛ الأدوات التالية تضيف مسار الاختيار
والتصحيح والإبطاء والنشر الذي استُخدم في 10 سبتمبر 2026.

**العدد المثبت في سجل تلك الجولة: 53 دعاء مرتبطًا بـ52 ملفًا فريدًا، وليس 110
ملفات منشورة.** سجل الجولة ليس جردًا جديدًا للإنتاج. بعض مراحل التصحيح أعادت
التوليد، فلا يُجمع عدد نواتج المراحل باعتباره عدد الأدعية الحالية.
الصوت مولّد من Google، وليس تسجيل مؤدٍّ بشري.

## الملفات

| الأداة داخل review | الوظيفة | ما قد تغيّره عند تشغيلها |
| --- | --- | --- |
| preview-dua-audio.mjs | عينات واختيار الصوت | ملفات محلية؛ التوليد بطلب صريح |
| publish-algieba-audio.mjs | التخطيط والتوليد الأولي والنشر | Storage وحقول الصوت فقط في وضع النشر |
| dua-speech-text.mjs | مطابقة نص النطق بالإملاء الرسمي | لا تغيّر نص العرض |
| repair-algieba-audio.mjs | خطة إصلاح الرموز وعينات محلية | لا تملك مسار نشر |
| preview-algieba-pacing.mjs | مقارنة الإلقاء والسرعة | توليد عينات محلية فقط |
| dua-speech-vowels.mjs | حركات عادية لنص النطق | لا تغيّر النص القرآني المعروض |
| finalize-algieba-audio.mjs | 31 تصحيحًا و22 أداءً محفوظًا، ثم الإبطاء والنشر | النشر منفصل وبشروط نسخة المصدر |
| bundle-final-audio.mjs | تجهيز أصول Flutter من الملفات المتحقق منها | ملفات محلية فقط |

الملف `audio-voice-selection.json` يوثق اختيار الصوت والعينة التاريخية،
ولا يمنح تصريح تشغيل جديدًا أو اعتمادًا شرعيًا. العينة لا يعاد اعتبارها
معتمدة إلا بمطابقة بصمة البايتات وسجل اعتماد السماع.

## اختبارات بلا اتصال بالإنتاج

المتطلبات: Node.js 20 أو أحدث، و`ffmpeg` و`ffprobe` في PATH.
من جذر المستودع:

```sh
npm ci --no-audit --no-fund
npm run test:audio
node --test scripts/generate_dua_audio.test.mjs
npm run lint
```

الاختبارات تستخدم النصوص العامة والبصمات في
`review/fixtures/algieba-original-records.json`، وليست نسخة Firestore أو
روابط تحميل حقيقية. اختبار الإبطاء يصنع نغمات وصمتًا في الذاكرة بواسطة
FFmpeg؛ لا يحتاج التسجيلات الخاصة ولا يطلب توليدًا مدفوعًا.

## التشغيل الحقيقي: مقيد بالدفعة التاريخية

هذه ليست أداة عامة لأي عدد من الأدعية. أدوات Algieba مثبتة على
`dhakker-160d0` و53 سجلًا؛ تغيير العدد أو النص أو بصمة المصدر يوقفها.
لا تغيّر `EXPECTED_COUNT` إلى 110 لتجاوز الحماية.

لا يعيد استنساخ المستودع إنشاء حالة المشغّل السابقة. مراحل التصحيح والنشر
تحتاج الأصول المحلية الأصلية: manifest التسجيلات الأولى، اللقطات الخاصة
قبل النشر، ملفات MP3، وعينة السرعة المعتمدة وسجلها. تبقى هذه الملفات خارج
Git. استعدها من أرشيف المشغّل الموثوق؛ لا تستبدلها ببيانات fixture للاختبارات.
بعد تغيّر الإنتاج، إعادة تشغيل `--prepare` أو `--plan` قد تُرفض عمدًا.

الأوضاع الأصلية، للتوثيق وليس طلبًا لتشغيلها:

```text
preview-dua-audio.mjs       [--generate] [--compare | --compare-more]
publish-algieba-audio.mjs   --plan | --generate | --publish | --verify
repair-algieba-audio.mjs    --prepare | --sample | --generate
preview-algieba-pacing.mjs  --chirp | --directed
finalize-algieba-audio.mjs  --prepare | --generate | --validate | --publish | --verify
```

النشر يتطلب أيضًا `--confirm-project=dhakker-160d0 --confirm-count=53`.
التوليد قد يستهلك حصة مدفوعة؛ قد تختلف الأسعار والحصص عن التقديرات التاريخية
داخل السكربتات. راجع التسعير والحساب قبل طلب توليد جديد.

التوكن قصير العمر عبر متغير البيئة `GOOGLE_ACCESS_TOKEN`، لا داخل الكود.
لا ترفع `.local/` أو مفاتيح الخدمة أو سجلات الرفع أو روابط تحمل
`token=`. مفاتيح البيئة والأصول الناتجة مستبعدة في `.gitignore`.

## حدود التحقق

نجاح الاختبارات يثبت حواجز الشيفرة التي تغطيها، ولا يثبت نطق جميع التسجيلات
أو جواز المحتوى أو اكتمال النشر الحالي. راجع السماع والمصدر قبل أي نشر جديد.
رفع هذه الأدوات إلى GitHub لا يعيد توليد الصوت ولا يغيّر Firebase أو الويب.
